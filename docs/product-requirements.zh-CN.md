# HanYu Cards 商用产品需求与验收基线

版本：2026-09-21。目标用户已确认：**个人或家长使用的学习产品优先**。本文区分已经实现的工程基础与仍需完成的商用要求，不将原型、构建成功或本地测试等同于正式上线。

## 1. 产品定位与首发边界

帮助学习者完成“选等级 → 学词 → 主动回忆 → 间隔复习 → 情景应用 → 查看进步”的每日学习闭环。首发形态为移动优先 Web/PWA，提供本地学习与数据迁移；原生商店发布另行验收。

| 用户 | 核心任务 | 首发约束 |
| --- | --- | --- |
| 个人汉语学习者 | 每天学习、复习错词、练习生活表达、保留学习记录 | 不要求注册；HSK 1–3；当前界面为英语 |
| 家长辅助使用者 | 安排每日目标、与学习者共同练习、查看进度、备份 | 一浏览器一份进度；家长管理设备；不能宣传已有家长控制功能 |
| 儿童独立使用者 | 年龄适配学习、家庭档案、受限互动 | 尚未支持；需教研适龄审核、监护流程和独立发布评估后才能开放 |

现有课程按照成人 HSK 使用场景编写，校园、购物、就医等场景并不自动构成儿童课程。不得把“家长可辅助使用”宣传成“儿童专用产品”。

首发不以学校管理、班级作业、社交排名、广告、订阅计费或无限 AI 为必需能力。跨设备迁移先使用可校验备份；自动云同步是单独的后续能力。

## 3. 内容质量流程

自动校验负责发现空字段、重复ID、同义选项、可疑姓氏释义及多音字，不能替代教师校对。每个发布内容包记录版本、来源提交、转换方式、审核人和审核日期；修订保持稳定wordId，避免已有学习记录断链。

现有词库是2,209条本地导入数据；“HSK 1–3”不能替代对HSK 2.0/3.0映射规则的说明。词典原始释义常包含多种读音，教学首义需要专门筛选。验收时常用词抽检零已知严重错误，发布包全部词条有审核状态，6个任务逐一验证对话、拼音、文化说明和答案。医院场景仅作为语言练习。

授权审核保留软件LICENSE、词库及上游字典来源、字体/图标/图片来源，明确每类材料的使用条件；不能从项目仓库的MIT标记推断全部上游材料均已审核。

## 4. 数据、隐私与家庭使用

- 学习记录默认只在设备，备份不含聊天或在线AI授权；备份文件为明文，用户可自行迁移与删除。
- 当前聊天仅在页面内存；在线请求仅在明确开启后发送。服务器筛选允许的学习上下文；响应存储关闭不等于供应商零保留。
- 关闭在线AI停止后续发送，不能撤回已经发送的数据。服务器/入口日志有独立保留期，由运营方填写，不默认宣称不收集IP。
- 多人共用同一浏览器目前会共用进度和设置。推出家庭档案前需在试用说明中明确；家长控制必须作为实际功能交付，不能以提醒文字替代。
- 如果确定向儿童独立提供服务，再由发布地区、年龄段和实际数据处理方式决定相关规则及审核事项。本文不假定销售地区或给出一套适用于所有地区的法律结论。

## 5. 运营、质量与商业验证

以下为首发目标，尚未作为实测成绩：

| 维度 | 目标与验收方式 |
| --- | --- |
| 可靠性 | 已承诺保存的进度在刷新/退出后保留；导入失败不破坏旧数据；严重数据丢失与未授权请求缺陷为0 |
| 性能 | 指定中端手机与移动网络下首页LCP目标≤2.5秒；本地翻卡交互目标≤100ms；记录设备/网络/版本，不能用桌面build时间代替 |
| 可用性 | 测试Chrome/Edge、Android Chrome、Safari/iOS PWA，最新两个主要版本及实际支持的WebView；记录存储、语音、文件下载差异 |
| 服务 | 正式部署可用性初始目标99.5%/月；AI错误率、延迟、并发、额度与预算有监控；超限可关闭在线AI保留学习功能 |
| 安全 | 发布时依赖扫描无未处置高危/严重问题；无客户端密钥；恢复路径、输入边界、限流、网关绕过均有测试 |
| 用户试用 | 至少10位目标用户（含家长）完成7天使用；记录首次完成一组学习所需帮助、备份恢复成功率、内容错误及付费意愿；记录真实样本与结果 |
| 支持 | 有可用支持邮箱、反馈模板、内容勘误渠道；严重数据/安全问题目标1个工作日响应；明确实际可承担的服务时段 |

商业验证顺序：先确认用户愿意持续学习及数据可靠，再测试离线内容包/一次性付费的接受度；需要生成式AI时单独核算按用户额度的成本。金额、付费渠道、退款规则、税费与地区尚未确定，不能把模拟按钮或默认环境变量当作支付完成。订阅并非本次已确认的首发要求。

## 6. 发布里程碑

1. **工程加固版（本次）**：实现P0技术基础、提交可运行代码与测试、生成缺口清单。验收不需要生产密钥。
2. **封闭试用版**：完成内容校对、隐私和支持资料、HTTPS试用环境、目标设备离线/恢复/升级验收；招募个人及家长试用。先使用本地或演示助教。
3. **正式基础商用版**：通过全部P0发布门槛，完成运营和内容质量责任人签字；依据选定渠道完成收款或商店流程后才能对外收费。
4. **家庭和在线服务版**：按真实反馈交付家庭档案、家长模式；真实AI上线前交付认证网关、持久化配额、预算监控及供应商数据处理配置。

产品负责人需最终补齐：销售地区、目标年龄、运营主体/支持联系、发行渠道、是否收费及方式。代码开发、测试和可审阅配置可先完成；公开发布需这些真实业务信息与目标环境的验收结果。
