# 百词斩风格前端视觉优化计划

## 目标

把 HanYu Cards 优化为强汉字识别、卡片化学习、温暖明快、反馈清晰的汉语学习界面。视觉方向参考百词斩类学习产品的常见体验特征，但不使用其品牌标识、插画、商标、文案或专有视觉资产。

## 已有基线

- 应用外壳位于 [src/pages/ShellLayout.vue](../src/pages/ShellLayout.vue)，底部包含学习、任务、练习、词典和进度五项导航。
- 核心页面位于学习、任务、练习、词典、进度和设置模块。
- 全局视觉主要由 [src/assets/app.scss](../src/assets/app.scss) 和 [src/assets/scenarios.scss](../src/assets/scenarios.scss) 控制。
- 页面已经使用部分弹性布局和 `clamp()`，但仍需收敛固定宽高、绝对定位和硬编码断点。

## 设计令牌

| 用途 | 颜色 | 语义 |
|---|---|---|
| 主色 | `#167c80` | 学习、主要操作、进度 |
| 深墨绿 | `#163033` | 标题、正文、汉字 |
| 阳光橙 | `#ffbd54` | 今日目标、XP、奖励 |
| 温暖橙红 | `#a8422d` | 拼音、重点、错误 |
| 完成绿 | `#4f8f34` | 正确、掌握、完成 |
| 页面底色 | `#f6f8f4` 至 `#eef7f1` | 温暖自然的学习环境 |
| 卡片底色 | `#fffdfa` 或 `#ffffff` | 内容和操作容器 |

- 汉字使用流式展示字号，标题、正文和标签使用 `rem` 或 `clamp()`。
- 正确、错误、完成和禁用状态同时使用文字、图标或形状反馈。
- 阴影保持低强度，圆角和间距保持跨页面一致。

## 响应式规则

后续实现必须遵循：

1. 容器使用 `100%`、`min()`、`max()`、`vw`、`dvw` 和 `fr`。
2. 字号使用 `rem` 或 `clamp()`。
3. 卡片高度优先由内容和 `aspect-ratio` 决定。
4. 间距使用 `rem`、`em`、`clamp()` 和百分比。
5. 固定像素只用于边框、图标笔画、极小触控目标或小屏兜底。
6. 悬浮入口、底部导航和面板使用相对视口及 `env(safe-area-inset-*)`。
7. 断点只切换布局结构，不直接决定汉字和标题的绝对像素尺寸。
8. 顶部、底部和中间内容均避免在软键盘弹出时被遮挡。

布局范围：

| 场景 | 布局 |
|---|---|
| 窄手机 | 单列、底部导航、卡片全宽、评价区分行 |
| 宽手机/小平板 | 单列或轻量双列、任务进度横向化 |
| 平板 | 双列卡片、任务对话与表达并列 |
| 桌面 | 最大阅读宽度居中、任务侧栏与内容双栏 |

## 页面范围

- **学习页**：汉字卡主视觉、揭示阶段、今日进度、剩余词数和四档评价。
- **任务页**：任务路线、对话、核心表达、文化说明、提交反馈和已完成状态。
- **练习页**：突出汉字和选项，明确选择、正确、错误和下一题状态。
- **词典页**：搜索筛选始终可达，中等密度词条卡，窄屏单列。
- **进度页**：今日指标、下一步推荐、周活动、HSK 等级进度和任务完成情况。
- **设置页**：分组化设置、副作用说明、明确保存和重置操作。
- **AI 助手**：不遮挡主操作；窄屏接近全宽并避开软键盘和安全区。

## 实施阶段

1. 收敛全局颜色、字体、间距、圆角和阴影，重构外壳、学习页和底部导航。
2. 优化学习卡揭示、评价反馈、练习题反馈和即时鼓励。
3. 优化任务、词典、进度和设置页面。
4. 清理固定尺寸和绝对定位残留，补充响应式与视觉回归验证。

## 验收标准

- 主页面在窄手机、宽手机、平板和桌面下不横向溢出。
- 竖屏、横屏和软键盘状态下汉字、主要操作和输入区可读可操作。
- 卡片、导航、面板和内容主布局不依赖固定像素宽高。
- 无鼠标场景可完成学习、任务、练习和设置操作。
- 正确、错误、完成、禁用状态同时具有视觉和文字或图标反馈。
- iOS/Android 安全部位不遮挡导航、评价区和输入区。
- 界面不使用百词斩品牌资产、商标或未经授权素材。
