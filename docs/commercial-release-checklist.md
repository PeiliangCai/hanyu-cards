# 商用发布门槛

本清单用于版本放行。`[x]`仅代表仓库已有交付物；正式发布负责人需对实际部署、内容和业务资料验收。当前不应标记为“已可正式收费上线”。

## 仓库内工程交付

- [x] 前后端配置分离，客户端无供应商/网关密钥。
- [x] 备份、验证、导入预览与替换确认、保存失败提示及旧格式迁移。
- [x] 在线AI默认关闭，可撤销；明确传输字段，区分本地/演示/在线回复。
- [x] API输入限制、超时、错误响应、日志最小化、有限容量限流和服务端网关要求。
- [x] npm锁文件、CI、前后端测试和多阶段容器构建配置。
- [x] 修复学习反馈、每日统计和重复提交问题，补充回归测试。
- [x] 商用需求、内容审核入口、部署手册、隐私草案与来源声明。

执行与证据以 [validation-report.md](validation-report.md) 为准。构建成功不能替代下面的发布验收。

## 正式发布前仍须完成

- [ ] **内容负责人**：完成 [content-audit.md](content-audit.md) 所列词义、读音、多音字及HSK版本审核，记录逐条结果与内容版本。
- [ ] **产品负责人**：确认地区/年龄/首发渠道；家长辅助试用说明清楚当前一浏览器一档案且没有家长锁。
- [ ] **运营负责人**：替换 `public/privacy.html` 部署草案，填实际运营主体、支持联系、AI/托管供应商、日志保留期；提供与实际服务一致的用户条款。
- [ ] **内容/运营负责人**：复核词库的上游来源与授权、媒体素材、图标字体及完整归属声明。
- [ ] **发布负责人**：目标环境运行容器CI/smoke、TLS、域名、缓存和路由测试；记录镜像digest及配置，证明回滚可用。
- [ ] **QA**：完成目标手机/Safari/Android PWA离线重开、备份导出恢复、已有版本升级、存储额度不足及多标签测试。无Web Locks的环境暂不承诺并发编辑安全。
- [ ] **运营/QA**：完成真实用户试用、内容勘误、监控告警、支持与故障处理演练。
- [ ] **开启真实AI时**：部署身份认证与持久化额度网关；拒绝未授权调用；验证预算/并发/重启后的额度，完成供应商数据设置和真实响应验收。
- [ ] **开启收费时**：确认价格/渠道，完成支付、退款或恢复购买的真实验收与支持政策。此仓库没有实现支付系统。
- [ ] **发布原生版时**：使用实际签名身份、目标设备与当前商店要求验证，取得商店所需材料与发布资格。

## 每次版本放行记录

记录版本/提交、日期、支持平台、内容版本、各项验收人、自动化运行链接、设备记录、已知限制、上一可回滚镜像。P0缺陷（进度丢失、未经同意发送、错误教学首义、匿名付费接口等）未解决不得放行相关功能。能通过关闭在线AI隔离的故障，允许保持本地学习服务并明确告知用户。
